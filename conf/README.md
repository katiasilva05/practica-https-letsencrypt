# Configuración Apache

Esta carpeta se reserva para archivos de configuración de Apache que se entreguen como parte de la práctica. No se incluye una copia de `000-default.conf` porque la configuración concreta depende del servidor y no conviene sobrescribirla con una plantilla genérica.

Antes de entregar una configuración real, elimina claves privadas, contraseñas y cualquier dato específico que no deba compartirse.
